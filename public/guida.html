📋 Nuovo cliente: il suo sito

Segui i passi in ordine. Scrivi il nome del cliente qui sotto: i link e gli indirizzi si compilano da soli. Le spunte restano salvate su questo telefono.

⭐ Solo la prima volta in assoluto

Apri github.com/l13291221-cmyk/Ristorante-/settings e nella parte General spunta «Template repository». Fatto una volta, vale per sempre.
Non modificare mai il sito demo (Ristorante-): tutte le copie partono da lì.

Il sito sarà: https://l13291221-cmyk.github.io/nomecliente/

1. Crea la copia del sito

  1. Apri Crea copia dal modello (è il pulsante «Use this template → Create a new repository»).
  2. Repository name: scrivi nomecliente
  3. Lascia Public e premi Create repository.

2. Metti il sito online

  1. Apri Impostazioni Pages del sito.
  2. In Build and deployment → Source scegli Deploy from a branch.
  3. In Branch scegli main e cartella / (root) → Save.
  4. Aspetta 1-2 minuti, poi apri il sito e controlla che si veda.

3. Crea la chiave (token) solo per questo sito

  1. Apri Nuovo token GitHub.
  2. Token name: nomecliente · Expiration: la più lunga disponibile (se c'è una data, segnatela in calendario).
  3. Repository access → Only select repositories → scegli nomecliente. Solo quello, mai «All repositories».
  4. Permissions → Repository permissions: Contents = Read and write, Pages = Read and write.
  5. Generate token e copialo subito (inizia con github_pat_): si vede una volta sola.

4. Scegli un PIN nuovo per il cliente

PIN proposto: ——————
Mai lasciare 123456: è il PIN del modello, lo conoscono tutti.

5. Imposta il PIN sul sito del cliente

  1. Apri il pannello del sito (oppure il sito → tasto Amministratore).
  2. PIN: 123456
  3. Scheda Pubblica: incolla il token del passo 3.
  4. Scheda Sicurezza: PIN attuale 123456 → nuovo PIN (quello del passo 4) due volte.
  5. Scheda Pubblica → Pubblica ora. Dopo 1-2 minuti il nuovo PIN vale per tutti.

6. Collega tutto all'ordine

  1. Apri l'Admin e trova l'ordine del cliente.
  2. Nel campo Link sito del cliente incolla https://l13291221-cmyk.github.io/nomecliente/ → Salva.
  3. Apri «PIN e token solo per questo cliente»: metti il PIN del passo 4 e il token del passo 3 → Salva.
Quando il cliente paga, vede da solo il link del sito, il PIN, il token e le istruzioni per modificarlo.

7. Contenuti del cliente (facoltativo)

Se il cliente ti ha mandato logo, foto, menu e orari, puoi inserirli tu dal pannello (schede Dati, Orari, Menù, Immagini) e premere Pubblica. Altrimenti li mette lui dopo il pagamento, con il PIN e il token che vede nella pagina dell'ordine.

8. Dopo il pagamento

  • Nell'admin l'ordine diventa ● Pagato.
  • Premi 🧾 Ricevuta e salvala (serve per i tuoi conti).
  • Se è Premium: il cliente scarica da solo il QR code; il dominio www.nome.it si collega dal pannello del sito (Pubblica → Il tuo dominio).
