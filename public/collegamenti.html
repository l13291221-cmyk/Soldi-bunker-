Più fonti colleghi, più negozi trova «Trova clienti» con 🌐 Tutte le fonti (i doppioni vengono tolti da soli). OpenStreetMap è sempre attivo e gratis. Le altre chiedono una chiave: segui i passaggi, incollala nel riquadro dorato e premi Salva, poi Prova.

📍 Google Maps …

È la fonte con più attività e con i numeri più aggiornati. Fino a 60 risultati per ricerca.

💶 Google chiede la carta, ma ogni mese c'è una parte gratuita (circa 1.000 chiamate con telefono e sito: controlla il listino). Una ricerca usa fino a 3 chiamate. Il limite qui sotto ferma il sito prima di uscire dalla parte gratuita.
  1. Apri console.cloud.google.com con il tuo Gmail, scrivi un nome (es. nerodoro) e premi Crea.
  2. Menu ☰ → Fatturazione → collega un account di fatturazione (la carta). Senza, Google non risponde.
  3. Apri Places API (New) e premi Abilita. Deve essere quella con «(New)».
  4. Apri Credenziali → Crea credenziali → Chiave API → copiala (inizia con AIza).
  5. Tocca la chiave appena creata → Limitazioni API → Limita chiave → spunta solo Places API (New) → Salva.
  6. Blocco di sicurezza in più: Quote di Places API (New) → richieste al giorno → 30.
  7. Incolla la chiave qui sotto → Salva → Prova.

🧭 HERE …

Le mappe usate da molte auto: tante attività con telefono e sito. Fino a 100 risultati per parola cercata.

💶 Account gratuito con una quota mensile ampia (circa 30.000 chiamate al mese, controlla sul listino HERE). Il limite proposto resta sotto.
  1. Apri platform.here.com → crea un account gratuito e conferma l'email.
  2. Vai su Access Manager → Apps → Register new app → scrivi nerodoro → Register.
  3. Nell'app appena creata apri la scheda Credentials → API Keys → Create API key → copia la chiave.
  4. Incolla la chiave qui sotto → Salva → Prova.

🚗 TomTom …

Un altro elenco di attività, con telefono e sito. Fino a 100 risultati per parola cercata.

💶 Gratis senza carta: circa 2.500 chiamate al giorno (controlla sul listino TomTom). Il limite proposto è 2.000 al giorno.
  1. Apri developer.tomtom.com → registrati e conferma l'email.
  2. Vai su Dashboard → Keys: la chiave My first API key è già pronta → copiala.
  3. Incolla la chiave qui sotto → Salva → Prova.

🔒 Dove finiscono le chiavi

Restano sul tuo sito e nel backup cifrato su GitHub (come gli ordini). La pagina ne mostra solo le ultime 4 lettere. In alternativa puoi metterle su Render → Environment: GOOGLE_PLACES_KEY, HERE_API_KEY, TOMTOM_API_KEY. Quella incollata qui vale più di quella di Render.
