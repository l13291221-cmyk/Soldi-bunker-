# Auto-clicker

1. Installa la libreria (una volta sola): `pip install pyautogui`
2. Apri il terminale nella cartella del file e lancia: `python auto_clicker.py`
3. Hai 5 secondi: metti il mouse dove vuoi cliccare e non muoverlo. Da lì in poi clicca da solo.

Per fermarlo: **CTRL+C** nel terminale (oppure porta il mouse in un angolo dello schermo).
